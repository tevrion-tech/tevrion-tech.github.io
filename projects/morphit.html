Morphit

Convert any file on Windows with one gesture.

Download for Windows GitHub

Free, version 1.4.0, 184 MB. Or winget install morphit

No window to open.

Hold Ctrl and drag a file a little in Explorer, on the desktop or out of Outlook. An orbit of formats opens under the cursor; let go on one, and the result lands next to the original.

What it does

  • Office and PDFWord, Excel and PowerPoint to and from PDF; PDF to Word or Excel
  • PDF toolsMerge, split, compress, password, stamp, page numbers
  • ScanPhone photos of paper to a straight A4 PDF with searchable text
  • PrivacyHide IDs, card numbers and IBANs; remove metadata
  • Pictures and videoHEIC, WebP, AVIF, MP4, MOV and more; shrink for e-mail
  • RecipesChain steps into one choice, such as PDF, stamp, password, Outlook

Nothing leaves your PC.

Every network API is banned in Morphit’s code. A line that could upload a file stops the build:

var http = new HttpClient();

error RS0030: The symbol 'HttpClient' is banned
in this project: Morphit works offline
